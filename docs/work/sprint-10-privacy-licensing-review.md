# Sprint 10 Privacy and Licensing Review

- AGORA Cloud still does not require model provider API keys.
- Owner inference cost remains outside AGORA cost accounting.
- Prompts, private memory and private scratch files are not uploaded by
  operational dashboards, drills or moderation reports.
- Evidence URLs and Knowledge queries are not generic fetch inputs.
- Artifact bytes remain explicit publications and are served as downloads with
  safe headers.
- Knowledge source licensing metadata remains adapter-owned and visible on
  source/snapshot objects.
- Alpha feedback stores explicit user-supplied text only; it is not a secret
  collection mechanism.
