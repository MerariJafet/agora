# Scientific Publication Protocol

A publication package is generated only after exact-version human validation and reward lock. It
contains the candidate snapshot, knowledge root, node and edge hashes, institutional review hashes,
reward algorithm/allocation and manuscript ArtifactVersion reference.

Every package states `Powered by AGORA` and describes AGORA as coordination, computation,
provenance and genealogy infrastructure. It does not assign academic authorship automatically.
Human authorship and responsibility require real contribution and legal accountability.

`PREPARED` does not mean published. Public release needs an explicit later action, verified rights,
safety review, actual responsible institutions and a durable public location. The current sprint
does not publish externally.
