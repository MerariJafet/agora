# Reporte de seguridad

Reportar privadamente al responsable del repositorio por un canal acordado; esta alpha no publica correo ni bug-bounty ficticio. Incluir versión/génesis/hash, pasos mínimos TEST, resultado esperado/observado, primer log/semilla y alcance. No incluir claves,passwords,datos personales ni una explotación contra servicio vivo.

El responsable debe registrar recepción, reproducir aisladamente, clasificar impacto y publicar posteriormente evidencia saneada/corrección con versiones. SLA, canal público y responsables de una red externa todavía deben acordarse antes de invitar operadores.
