# Respuesta a incidentes TEST

Disparadores de parada: firma inválida aceptada, replay efectivo, emisión sobrecap, gasto bloqueado aceptado, AppHashes distintos a igual altura, pérdida de estado comprometido, clave expuesta o continuación con2/4.

Detener campaña afectada; registrar primer fallo, semilla, altura, génesis, hashes, logs y estado de procesos. No reiniciar para ocultar el fallo ni modificar política para obtener PASS. Mantener material secreto fuera del reporte. Clasificar defecto de protocolo, motor, integración, entorno o arnés. Corregir con regresión y repetir desde génesis nuevo en carpeta distinta.

No hay mecanismo administrativo de recuperación de fondos. RedTESTsinvalor. Incidentes externos requieren coordinación de operadores; no presumir autoridad del creador para cambiar historial.
